## Concrete Novelty Evidence

| Novelty | Mechanism | Measurement |
| --- | --- | --- |
| Fingerprint-bounded model budget | Compute dataset fingerprint before training and benchmark only supported suggested candidates. | models_evaluated_datacortex vs models_evaluated_broad_pool |
| Task-aware target suppression | Market-basket structure prevents automatic supervised target selection. | failure_mode_validation.csv and Kaggle Groceries E2E artifacts |
| Integrity-aware lifecycle | Fingerprint consistency gate records row/sparsity/task anomalies across mutations. | VALIDATION_RESULTS.md integrity column and planner event artifacts |
| Pre-execution code safety gate | Generated Python is parsed by AST and blocked before execution on unsafe syntax/API use. | tests/test_code_validator.py and static attack block-rate evidence |
| Observable long-running execution | Phase events and checkpoints expose pipeline state while modeling or reporting is running. | demo_outputs/*/demo_events.json and checkpoint JSON |

## Benchmark Limits

- The broad pool is a local sklearn-style reference pool, not an external AutoML framework.
- Scores use repository fixtures and available Kaggle CSVs only.
- The broad pool can evaluate more models than DataCortex; the gap column shows the cost of bounded fingerprint selection.
- Regression R2 and classification accuracy are not averaged into a leaderboard metric.
